How to use this map
1) Start with the Top Filter panel (Core, Action, Decision, Precinct, Category, Trend).
2) Pick one layer per filter group for the cleanest view.
3) Use Precinct + Category together to narrow the map quickly.
4) Crime Type/Category filters drive heatmaps; core count layers marked All Incidents stay citywide totals.
5) Add Shift layers only when you need time-of-day context.
6) Use spike and action marker layers for exact response points.
Tip: Too much overlap means too many layers are active.
